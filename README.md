# Java Test Task

## Описание
Решение тестового задания на Java 11.

## Задание 1
Программа:
- принимает два числа
- сравнивает их
- выполняет арифметические операции (сложение, вычитание, умножение, деление)

## Задание 2
Программа:
- принимает две строки
- сравнивает их на идентичность

## Задание 3
Программа:
- выводит чётные числа из массива от 1 до 10
